# Interactive-Prototype-Creation
Build a clickable prototype

Choose a simple app

For example, create a Food Delivery App prototype.

You can make these screens:

Splash Screen
Login / Sign Up
Home Screen
Restaurant/Menu Screen
Food Details
Cart
Order Confirmation
2. Make your Figma prototype interactive

Connect the screens so that:

Login → Home → Restaurant → Food Details → Cart → Order Confirmation

Add interactions such as:

Button clicks
Page navigation
Back buttons
Menu selection
Add to Cart
Checkout
Simple transitions/animations
3. Test the prototype

Ask 2–3 people to try tasks such as:

"Open the app, select a restaurant, add a food item to the cart, and complete the order."

Observe where they get confused or stuck.

Record simple feedback:

User	Feedback	Change Made
User 1	Couldn't find Cart	Made Cart button more visible
User 2	Checkout was confusing	Simplified checkout screen
User 3	Back button was unclear	Added clear back icon

# Interactive Prototype Creation

## Project Overview

Created a clickable mobile app prototype to simulate real-world user interactions.

## Objective

The goal of this project was to convert wireframes into an interactive prototype and understand how users interact with a mobile application.

## Key Features

* Converted wireframes into an interactive Figma prototype
* Added navigation between screens
* Added transitions and animations
* Created a complete user flow
* Conducted basic user testing
* Collected feedback and improved the design

## Prototype Flow

Login → Home → Restaurant → Food Details → Cart → Order Confirmation

## Tools Used

* Figma
* UI/UX Design
* Prototyping
* User Testing

## User Testing

The prototype was tested with a few users to identify usability issues.

### Feedback

* Improved button visibility
* Simplified navigation
* Made the checkout process easier to understand
* Improved back-button placement

## Expected Outcome

This project helped me learn how to create interactive prototypes, design navigation flows, conduct basic user testing, and improve designs based on user feedback.
